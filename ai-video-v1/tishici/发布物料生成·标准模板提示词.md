# 发布物料生成 · 标准模板提示词

> 用途：每次新视频做完（成片渲染后、发布前），把本文档交给 Agent，为这支视频产出**标题 + 作品描述 + 封面文案**，并把封面以 Remotion Cover 合成为图片落地。与 ai-video 流水线解耦，可单独使用。
>
> 输入：本期「主题」「核心钩子」「成片脚本/分镜」（发布物料全部由这些现写，不套上一条的死文案）。
> 样例工程（海特验证过的落地姿势）：`videos/gongkao/first-class/` —— `out/main.mp4` + `out/cover.png`。

---

## 一、标题（产出 6–8 条，分三类，各留关键词）

**规则**
- 三条子类各给 2 条以上，供按平台调性挑选。
- 每条标题里埋入**搜索/人群关键词**（例：公考、国考、省考、2027、应届生、往届生）——从这里挖受众。
- 用数字和具体时间制造紧迫（例：「2027国考还有不到一个月报名」「90% 的人」）。
- 标题要能查得到、有画面感，长短屏通用。

**三类写法**

| 类 | 作用 | 句式示例 |
|---|---|---|
| 钩子向 | 首页信息流抓停留，卖冲突/悬念/认知盲区 | 「2027国考还有不到一个月报名，90%的人却连国考省考都分不清！#」 |
| 干货向 | 明确人群、利于搜索与收藏 | 「公考扫盲：国考vs省考到底怎么选？应届生和往届生答案完全不同」 |
| 行动向 | 用紧迫/指令感引导点击 | 「2027国考报名马上开始，这几个关键区别你搞懂了吗？」 |

## 二、作品描述（一段式模板骨架）

```
#标签 #标签 #标签（3–4 个核心，首屏）

{一句话钩子——复述主题的紧迫/冲击点}

一分钟帮你扫盲👇

{干货：分类对比，用 emoji 分点。每条「对象 + 特征」}
（例：📌 国考＝中央机关统一招录：招部委/税务/海关；全国统一时间，大半只招应届生。）

✅ {人群建议一}（例：应届生：两个都报。）
✅ {人群建议二}（例：往届生：主攻省考。）

💡 记住一句话：{口诀金句}。

{solid CTA，含专场引导 + 评论区互动钩子}
（例：2027国考报名马上开始，赶紧去看公告，别错过这次上岸机会！评论区留下你的身份（应届/往届），帮你分析该考哪个⬇️）
```

**硬性点**
- 开头措辞≈脚本开篇 hook，别另起炉灶。
- 「干货/建议/口诀」必须与成片脚本内容一致，禁止编造脚本里没有的结论。
- 结尾留**评论区互动钩子**（让人填信息/报身份），利于算法和转发。
- 核心标签 3–4 个放首屏，次要标签放末尾。

## 三、封面文案（主 + 副，可给 2–4 套组合）

**组合写法**（从标题/钩子/口诀里取）

| 组合 | 主标题 | 副标题/题签 |
|---|---|---|
| 对比冲击（主推） | 两个对象用 vs（例：国考 vs 省考） | 先搞清楚再报名，别再赌错！ |
| 数据钩子 | 抓认知盲区+数字（例：90%的人连国考省考都分不清） | 2027国考报名倒计时⏰ |
| 人群直指 | 应届考哪个？往届考哪个？ | 应届两头抓·往届盯本省 |
| 口诀收口 | 朗朗上口金句（例：国考考中央·省考看地方） | 一分钟理清公务员考试 |

- 主标题**力求个位词、大字可读**（40 像素档以上能看清）；副题签短句。
- 可选带系列 IP 标签（例：公考扫盲 · 局长该学习了）。

## 四、封面落地（Remotion Cover 合成 + 导出）

每片**新建一个独立 Cover 合成**，不动正片分镜大字；用与正片同一皮肤/同一背景图，保证缩略图与视频一致。

**工程姿势（参考 `videos/gongkao/first-class/src/Cover.tsx`）**
- 新建 `src/Cover.tsx`：1280×720 静态布局，复用 `cards/skin`（`SK` 色版 / `FONT` / `inkOutline` / `surface`）+ 复用某张背景图（如 bg-open.png）铺满。
- 排版：右上系列标签 → 主标题放上方留白区（大号 + 墨蓝描边，可拆一行/两行）→ 主标题下纸感副题签（`surface(SK.sponge)`）。
- 顶部压暗渐变 + 四角暗角，保证白字/黄字压在浅色海水上也立得住。
- 注册进 `Root.tsx`：
  ```tsx
  <Composition id="Cover" component={Cover} durationInFrames={1} fps={30} width={1280} height={720} />
  ```
- 导出：
  ```bash
  npx remotion still src/index.ts Cover out/cover.png --frame=0
  ```

**验收**
- [ ] 封面与成片同画风、同背景角色（拿成片首帧 OS 对比）
- [ ] 主标题大字不被角色/字幕遮挡，留白区居中
- [ ] 副题签换行/裁切可读
- [ ] 标题、描述全文与脚本结论一致，无编造

## 五、完整提示词模板（可直接粘贴）

```text
为一支已渲染成片的短视频产出发布物料（动画风，仅自用）。输入：
- 主题：{主题}
- 核心钩子：{钩子}
- 成片脚本/分镜要点：{简要梗概}

产出四样：
1. 标题 6–8 条：钩子向/干货向/行动向各 2 条以上；每条埋人群与搜索关键词；
   用数字与具体时间做紧迫感（结合本期主题），不要沿用其他片的文案。
2. 作品描述一段：钩子开场 → 干货分点（emoji）→ 人群建议（应届/往届按主题替换）→
   口诀金句 → CTA+评论区互动钩子；核心标签 3–4 个放首屏；
   所有结论必须与脚本一致，禁止编造。
3. 封面文案 2–4 套：主标题（个位词、大字可读）+ 副题签；可选系列 IP 标签。
4. 封面落地：如需图片，新建 src/Cover.tsx（1280×720 静态，复用皮肤+某张背景图，
   右上系列标签 + 主标题留白区大字 + 纸感副题签；顶部压暗+四角暗角），注册进 Root，
   并用 `npx remotion still src/index.ts Cover out/cover.png --frame=0` 导出。
```
